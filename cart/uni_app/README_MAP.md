## 使用说明

### 1. 运行项目
```bash
# H5端运行
npm run dev:h5

# 微信小程序
npm run dev:mp-weixin

# App端
npm run dev:app
```

### 2. 位置权限
- 首次使用时会请求位置权限
- 如果用户拒绝，会使用默认位置（上海）
- 可以手动点击定位按钮重新获取位置

### 3. 功能特性
- 自动获取当前位置
- 显示当前城市
- 逆地理编码获取详细地址
- 支持点击选择城市
- 地图定位按钮

## 注意事项

1. **H5端跨域问题**
   如果在H5端遇到跨域问题，需要配置后端允许跨域访问，或使用代理。

2. **HTTPS要求**
   在生产环境中，获取位置信息需要HTTPS协议。

3. **百度地图配额**
   请注意百度地图API的调用配额限制。

## 问题排查

如果地图仍然无法显示，请检查：
1. 控制台是否有错误信息
2. 网络请求是否正常
3. 百度地图API Key是否有效
4. 位置权限是否已授予
