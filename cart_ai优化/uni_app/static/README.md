## 图标规格建议
- 所有图标建议使用PNG格式，支持透明背景
- 小图标(箭头等): 建议32x32px或更小
- 功能图标: 建议64x64px
- 大图标: 建议128x128px
- 背景图片: 根据实际需要调整尺寸

## 设计建议
1. 图标风格应保持一致，建议使用线性图标或面性图标
2. 颜色搭配应符合整体UI设计
3. 可以使用iconfont、阿里矢量图标库等资源
4. 确保图标在不同设备分辨率下显示清晰

## 临时解决方案
如果暂时没有图标资源，可以：
1. 使用纯色矩形作为占位符
2. 使用CSS绘制简单图标
3. 使用emoji符号作为临时图标
4. 下载免费图标库资源
