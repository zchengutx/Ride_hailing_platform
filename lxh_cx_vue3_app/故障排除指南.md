# 🛠️ 故障排除指南

## 🚨 常见问题及解决方案

### 1. API调用失败 (500错误)

**现象:**
- 控制台显示 "Request failed with status code 500"
- 微信登录二维码无法加载
- 发送验证码失败

**原因:**
- 后端服务未启动
- 端口配置错误 (应该是8899而不是8080)
- 数据库连接失败
- Redis连接失败

**解决方案:**
```bash
# 1. 检查后端服务是否启动
netstat -an | findstr "8899"

# 2. 启动后端服务
cd kitex-main/lxh_cx
go run main.go

# 3. 检查数据库连接
# 确保MySQL服务运行在 14.103.133.61:3306

# 4. 检查Redis连接  
# 确保Redis服务运行在 14.103.133.61:6379
```

### 2. 网络连接失败

**现象:**
- "无法连接到远程服务器"
- 页面加载缓慢或失败

**解决方案:**
```bash
# 1. 测试后端连接
Invoke-WebRequest -Uri "http://localhost:8899/v1/api/user/weChat" -Method GET

# 2. 检查防火墙设置
# 确保8899端口未被阻止

# 3. 重启服务
# 前端: Ctrl+C 停止，然后 npm run dev
# 后端: Ctrl+C 停止，然后 go run main.go
```

### 3. 微信登录二维码问题

**现象:**
- 二维码无法显示
- 显示空白或错误图片

**原因及解决:**
```javascript
// 问题: 后端返回PNG二进制数据，前端需要正确处理
// 解决: 已修复为使用Blob对象

// 检查控制台日志:
console.log('微信二维码获取成功') // 应该看到这个
```

### 4. 跨域问题

**现象:**
- CORS错误
- 请求被阻止

**解决方案:**
```javascript
// vite.config.js - 代理配置 (已修复)
proxy: {
  '/v1/api': {
    target: 'http://localhost:8899', // 正确端口
    changeOrigin: true,
    secure: false
  }
}
```

### 5. Token认证失败

**现象:**
- 401错误
- 自动跳转到登录页

**解决方案:**
```javascript
// 检查Token是否存在
console.log('Token:', localStorage.getItem('token'))

// 手动清除并重新登录
localStorage.removeItem('token')
localStorage.removeItem('userInfo')
```

## 🔍 调试步骤

### 第一步: 检查服务状态
```bash
# 前端服务 (端口3001)
netstat -an | findstr "3001"

# 后端服务 (端口8899) 
netstat -an | findstr "8899"
```

### 第二步: 检查控制台日志
打开浏览器开发者工具 (F12)：
- **Console**: 查看错误信息
- **Network**: 查看API请求状态
- **Application**: 查看localStorage中的token

### 第三步: 测试API连接
```bash
# 测试微信接口
Invoke-WebRequest -Uri "http://localhost:8899/v1/api/user/weChat" -Method GET

# 应该返回: StatusCode: 200
```

### 第四步: 重启服务
```bash
# 停止所有服务 (Ctrl+C)
# 然后重新启动:

# 后端
cd kitex-main/lxh_cx
go run main.go

# 前端 (新窗口)
cd lxh_cx_vue3_app  
npm run dev
```

## 🆘 紧急修复

如果所有方法都失败，尝试以下步骤：

```bash
# 1. 完全重置
cd lxh_cx_vue3_app
rm -rf node_modules
npm install

# 2. 清理浏览器缓存
# 按F12 -> Application -> Storage -> Clear storage

# 3. 重启计算机
# 有时候端口占用问题需要重启解决

# 4. 检查hosts文件
# Windows: C:\Windows\System32\drivers\etc\hosts
# 确保包含: 127.0.0.1 localhost
```
