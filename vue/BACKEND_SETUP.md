# 后端服务启动指南

## 问题说明

前端API调用返回403错误，这是因为后端服务没有运行或配置不正确。

## 解决方案

### 1. 启动后端服务

请确保您的后端服务正在运行在 **8888端口**：

```bash
# 进入后端项目目录
cd /path/to/your/backend/project

# 启动后端服务（具体命令取决于您的后端框架）
# 例如Go语言：
go run main.go

# 或者如果是其他语言：
# node server.js
# python app.py
# ./your-backend-binary
```

### 2. 验证后端服务

打开浏览器访问：
- http://localhost:8888/api/driving （应该返回JSON响应，不是404）
- http://localhost:8888/api/directionlite （应该返回JSON响应，不是404）

### 3. 检查代理配置

前端Vite已配置代理，API请求会自动转发到 `http://localhost:8888`：

```javascript
// vite.config.js 中的代理配置
proxy: {
  '/api': {
    target: 'http://localhost:8888',
    changeOrigin: true,
    secure: false
  }
}
```

### 4. API接口要求

后端需要提供以下接口：

#### POST /api/driving
**功能**: 计算两点间驾车距离和时间
**请求**:
```json
{
  "origins": "116.404,39.915",
  "destinations": "116.407,39.918"
}
```
**响应**:
```json
{
  "code": 200,
  "data": {
    "distance": "约2.5公里",
    "duration": "约8分钟"
  }
}
```

#### POST /api/directionlite
**功能**: 获取详细路线坐标
**请求**:
```json
{
  "origins": "116.404,39.915",
  "destinations": "116.407,39.918"
}
```
**响应**:
```json
{
  "code": 200,
  "data": {
    "polyline": [[116.404,39.915], [116.405,39.916], ...]
  }
}
```

## 前端功能说明

即使后端服务不可用，前端也会：

1. **优雅降级**: 自动使用直线距离计算
2. **状态提示**: 显示后端API状态（正常/离线/异常）
3. **无错误弹窗**: API错误只在控制台记录，不影响用户体验
4. **离线模式**: 提供基本的距离和时间估算

## 当前状态检查

在前端页面中：
1. 查看左上角的"后端API"状态提示
2. 🟢 **正常**: 后端服务可用
3. 🔴 **离线**: 后端服务未启动
4. 🟡 **异常**: 后端服务有问题

## 调试步骤

1. **检查后端服务**: 确保在8888端口运行
2. **检查控制台**: 查看详细的错误信息
3. **测试功能**: 点击"测试路线"按钮验证
4. **查看网络面板**: 检查API请求的响应状态

## 常见问题

### Q: 显示"后端API: 离线"
**A**: 后端服务没有启动，请启动后端服务在8888端口

### Q: 显示"后端API: 异常"  
**A**: 后端服务运行异常，检查后端日志和配置

### Q: 路线显示为虚线
**A**: 这是直线路径，说明API不可用，使用了降级方案

### Q: 距离时间显示"约XX公里，约XX分钟"
**A**: 这是估算值，因为后端API不可用

## 无后端测试

如果暂时没有后端服务，前端仍然可以：
- ✅ 正常定位
- ✅ 显示地址信息  
- ✅ 手动调整位置
- ✅ 绘制直线路径
- ✅ 估算距离时间

只是无法获得精确的驾车路线和实际通行时间。
